# 커뮤니티 앱 - 제품 문서

> 임시 프로젝트명입니다. 추후 사용자가 변경할 수 있습니다.

---

## 한 줄 설명

누구나 브라우저에서 게시글을 쓰고, 댓글과 좋아요로 대화를 나누는 웹 기반 커뮤니티 서비스.

---

## 타겟 사용자

| 구분 | 설명 |
|------|------|
| 주 사용자 | 브라우저에서 커뮤니티 활동을 하는 일반 사용자 |
| 접근 방식 | 별도 앱 설치 없이 웹 브라우저로 접근 |
| SEO 요구사항 | 공개 게시글은 검색 엔진에 노출되어야 함 |
| 기술 수준 | 비전문가 포함, 누구나 쉽게 사용 가능해야 함 |

---

## 핵심 기능

### 1. 회원 인증
- 이메일 + 비밀번호 회원가입 / 로그인
- OAuth 소셜 로그인 (Google, GitHub)
- 세션 유지 및 로그아웃

### 2. 게시글 CRUD
- 게시글 작성 (제목, 본문)
- 게시글 목록 조회 (최신순 / 인기순)
- 게시글 상세 조회
- 게시글 수정 및 삭제 (본인만 가능)

### 3. 댓글
- 게시글에 댓글 작성
- 댓글 목록 조회
- 댓글 수정 및 삭제 (본인만 가능)

### 4. 좋아요
- 게시글 좋아요 / 좋아요 취소 (토글)
- 좋아요 수 표시

### 5. 검색
- 게시글 제목 / 본문 키워드 검색
- 검색 결과 목록 표시

---

## 주요 유스케이스

### UC-01. 신규 사용자 가입 후 첫 게시글 작성
1. 사용자가 이메일 또는 Google/GitHub 계정으로 가입한다.
2. 가입 완료 후 게시글 작성 페이지로 이동한다.
3. 제목과 본문을 입력하고 게시글을 등록한다.
4. 등록된 게시글이 피드 최상단에 노출된다.

### UC-02. 기존 사용자의 게시글 탐색 및 반응
1. 사용자가 로그인 없이 공개 피드를 탐색한다.
2. 관심 있는 게시글을 클릭하여 상세 내용을 읽는다.
3. 로그인 후 좋아요를 누르거나 댓글을 작성한다.

### UC-03. 키워드 검색을 통한 콘텐츠 발견
1. 사용자가 검색창에 키워드를 입력한다.
2. 해당 키워드가 포함된 게시글 목록이 표시된다.
3. 원하는 게시글을 선택하여 상세 페이지로 이동한다.

### UC-04. 본인 게시글 수정 및 삭제
1. 로그인한 사용자가 자신이 작성한 게시글을 조회한다.
2. 수정 버튼을 눌러 내용을 변경하고 저장한다.
3. 또는 삭제 버튼을 눌러 게시글을 삭제한다.

### UC-05. 댓글을 통한 토론 참여
1. 사용자가 게시글 상세 페이지에서 댓글을 작성한다.
2. 다른 사용자의 댓글에 추가로 의견을 남긴다.
3. 자신의 댓글을 수정하거나 삭제한다.

## MVP 범위 외 (Non-Goals)

아래 기능은 초기 MVP에서 **제외**됩니다. 추후 로드맵에서 검토합니다.

| 기능 | 제외 이유 |
|------|----------|
| 실시간 채팅 / WebSocket | 구현 복잡도 및 인프라 비용 증가 |
| 팔로우 / 팔로잉 소셜 그래프 | MVP 핵심 가치와 무관한 복잡성 |
| 모바일 네이티브 앱 | 웹 우선 전략, 추후 PWA 고려 |
| 결제 / 구독 기능 | 비즈니스 모델 미확정 |
| 추천 알고리즘 | 최신순 / 인기순으로 충분한 MVP 단계 |
| 알림 시스템 (푸시/이메일) | 추후 사용자 피드백 기반 추가 |
| 첨부파일 / 이미지 업로드 | 추후 결정 (TBD) |
